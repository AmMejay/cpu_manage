API de Medições

API REST para cadastro, consulta, atualização e exclusão de medições de temperatura.

Rotas disponíveis

GET
/

Página inicial da API.

POST
/medicao

Cadastra uma nova medição.

GET
/medicao

Lista todas as medições.

GET
/medicao/temperatura_ideal

Lista medições com temperatura ideal.

GET
/medicao/:id

Busca uma medição pelo ID.

PUT
/medicao/:id

Atualiza uma medição existente.

DELETE
/medicao/:id

Exclui uma medição existente.

API desenvolvida com Node.js, Express e better-sqlite3.
